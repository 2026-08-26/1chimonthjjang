04 / PREPROCESSING JOURNEY

처음 받은 데이터는
바로 분석할 수 없었습니다.

실제 전처리 코드의 문제 확인 → 처리 → 결과 흐름입니다.

01 / DATE

날짜가 서로 달랐습니다.

날짜 문자열→datetime 변환

날짜형 변환 후 월·경기일 기준으로 맞췄습니다.

02 / REGION

지역명과 통계 형태가 달랐습니다.

지역별 Wide 통계→지역 표준화 · Melt

같은 지역을 같은 이름으로 정리하고, 월×지역 Long 데이터로 만들었습니다.

03 / PRICE

면적이 다르면 가격 비교도 달라집니다.

아파트 거래금액→거래금액 ÷ 전용면적

㎡당 가격을 만든 뒤 월·지역별 중앙값과 거래 건수를 집계했습니다.

04 / GAME

같은 날짜의 경기가 구분되지 않았습니다.

2019-09-19 OB–SK 더블헤더→해당 경기 제외

원 코드에서 1·2차전 구분 문제로 제외한 사례입니다. 모든 중복 기록을 일괄 삭제한 것은 아닙니다.

05 / WEATHER

선수 기록에 날씨가 없었습니다.

시간별 날씨 · 홈팀→경기 지역 매핑 → 일별 집계

기온·습도는 평균, 강수는 합계로 집계한 뒤 경기 날짜·지역으로 연결했습니다.

06 / MISSING

비어 있는 값은 0이 아니었습니다.

순이동 결측 · 필수 거래정보 누락→필수값 결측 행 제외

사회는 순이동 결측 행을, 경제는 거래일·금액·면적·지역코드 결측과 면적≤0을 제외했습니다.

처리 근거와 실제 제외량

사회 01_preprocess_social.py · 경제 04_preprocess_economy.py · 야구 02_preprocess.py / 03_weather_merge.py / 04_analysis.py
